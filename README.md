# GrantFlow 🚀

### Solana Grants. One Dashboard.

[![Solana](https://img.shields.io/badge/Solana-9945FF?style=for-the-badge&logo=solana&logoColor=white)](https://solana.com)
[![GitHub](https://img.shields.io/badge/GitHub-100000?style=for-the-badge&logo=github&logoColor=white)](https://github.com/skhaja007/grantflow)

GrantFlow is a comprehensive dashboard that aggregates all Solana ecosystem grants in one place. Connect your Phantom wallet, discover opportunities, and track your grant applications seamlessly.

## ✨ Features

- 🔗 **Solana Wallet Connection** - Phantom wallet support
- 📊 **Grant Discovery** - All Solana grants in one dashboard
- 🔍 **Search & Filter** - By category, funding amount, and deadline
- 📱 **Mobile Responsive** - Works perfectly on all devices
- 🏷️ **12+ Categories** - DeFi, NFT, Gaming, AI, Infrastructure, DAO, Content, Mobile, Payments, RWA, Privacy, Tools
- ⏰ **Deadline Tracking** - Never miss an opportunity
